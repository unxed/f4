# Состояние задачи BRANCHES.md

Дата проверки: 08-09-2026.

## Цель

Добавить в корень репозитория проверяемый инвентарь веток и рабочих деревьев,
чтобы после слияния задачи не оставались незаметными и чтобы несколько
Луноботов не принимали одну и ту же ветку за активную работу.

## Решения и инварианты

- Источники состояния — текущий `main`, список PR GitHub, локальные ветки и
  `git worktree list`; отсутствие PR не доказывает, что ветка принадлежит
  текущему инстансу.
- Слитая ветка помечается как завершённая, но её удаление не выполняется
  автоматически: рабочая копия общая, а удаление может уничтожить незавершённую
  работу другого инстанса.
- `BRANCHES.md` проверяется вместе с `CI.md` после каждого коммита в `main`.

## Текущее состояние

Корневой `BRANCHES.md` добавлен этим коммитом. Production-код не меняется;
на момент подготовки списка в `CI.md` нет незавершённых прогонов.
