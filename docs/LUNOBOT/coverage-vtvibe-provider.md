# Coverage: vtvibe provider

Задача по § 22 п. 3 инструкции Лунобота: повысить покрытие пакета `vtvibe`, начиная с `provider.go` (4,61% по Codecov main на момент взятия; пакет `vtvibe` — 54,49%).

В коммите добавлены тесты HTTP-провайдера: успешные Chat/Models с проверкой запроса и авторизации, строковый и составной JSON-контент, ошибки API и HTTP, отсутствие ключа, retry/cancellation, разбор statusError, backoff и вспомогательные функции.

Локальные Go-сборки и тесты не запускались согласно LUNOBOT.md; результат проверяется GitHub Actions.

Исправлен ожидаемый размер усечённого текста ошибки; коммит готов к проверке CI.

Lint CI нашёл три непроверенных результата записи в тестовых HTTP-обработчиках; они исправлены.

Vet CI уточнил требование: результат io.WriteString теперь присваивается обеим переменным.

Исправлено форматирование выравнивания таблиц тестов по требованиям CI.

Восстановлено выравнивание полей в стиле gofmt исходного пакета.

Добавлен завершающий перевод строки, обязательный для gofmt.

Добавлен временный CI probe для получения точного вывода gofmt; он будет удалён до слияния.
