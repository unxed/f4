## Решения и инварианты

- Счётчики не включают служебную запись `..`; файлы и каталоги считаются раздельно.
- Свободное место запрашивается только для локального `OSVFS`. Для удалённых и виртуальных панелей неизвестные значения не показываются.
- Значения вычисляются при отрисовке строки, поэтому после смены каталога отображается состояние нового каталога.
- Существующее поведение строки текущего элемента, выделения и итогового размера не меняется; добавляется только контекст каталога и диска.
